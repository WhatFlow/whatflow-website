## Start with the customer’s job

A floating icon can be visible, but it can also cover a cart control or feel detached from the store’s design. A theme-matched WhatsApp entry point can sit where the shopper naturally needs help, such as beside product details or support information.

## Where each approach helps

Floating widgets can be useful for persistent access. Inline or native-feeling placement can be better for a deliberate design. Neither placement is automatically superior on every screen; the customer’s task should determine the location.

## Test the button after the page changes state

Hypothetical example: compare a help button beside a size guide with a floating contact icon. Open a long product title, select an unavailable variant and then open the cart drawer and consent banner. Check whether the buyer can still find the relevant warning, reach checkout and discover help. A tidy first screen does not establish that either placement works through the purchase.

Try keyboard navigation and an input with the phone keyboard visible where relevant. Record the precise state that fails before changing layout settings. WhatFlow Business API’s free-forever theme-fitting buttons remove the need to buy a widget simply for a WhatsApp entry point, while the placement still needs to serve the store’s particular page.

Preview the store on a narrow phone screen and a desktop. Open the cart drawer, sticky purchase controls and accessibility navigation, and make sure the contact entry point supports rather than blocks buying.

Consider [multi-channel widget alternatives](https://whatflow.tech/compare/whatflow-vs-chaty) when several contact destinations are genuinely required.
