## Start with the customer’s job

A brand with a mobile app has a valuable notification surface. Many Shopify stores do not have that installed audience. WhatsApp can offer a persistent customer conversation without requiring the merchant to persuade every shopper to install a dedicated shopping app first.

## Where each approach helps

Mobile push is useful when customers already use the app and the message should deep-link into its experience. WhatsApp is useful for an audience that already talks there. Both channels still need appropriate permission and a sensible contact frequency.

## Separate an existing app audience from a new app project

For a hypothetical budget review, split customers already using the shopping app from those who would need to install it. Ask what the push notification is intended to do for the existing audience and which part of app maintenance would actually be incremental. Compare that with the permissioned WhatsApp audience instead of charging the entire app program to one message. WhatFlow can provide Shopify WhatsApp workflows when the store wants that conversation without commissioning its own shopping app. Inspect the destination and the customer’s route to help in both cases. Choose the operating scope from observed audience needs, not an assumption that every store requires or should abandon a mobile app.

Compare an order update for existing app users and WhatsApp users. Track whether the destination opens correctly, whether the customer can ask a question and how the team sees the order behind that question.
