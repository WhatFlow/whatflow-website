## Start with the customer’s job

A direct API connection gives developers control. It also leaves the business responsible for the application around the connection: Shopify events, customer context, delivery state and a safe place for people to reply. Sending a successful test message is the beginning of that project.

## Where each approach helps

A custom build can be appropriate when the requirements are unusual or span several systems. A packaged app is attractive when the workflow is a familiar Shopify task and the merchant wants a maintained operating tool.

Compare [API infrastructure and application layers](https://whatflow.tech/compare/whatflow-vs-360dialog) when deciding which components to buy.

## The practical cost difference

Compare engineering, hosting, maintenance and human support access with the app subscription and usage charges. Meta delivery fees still need to be considered in either architecture; direct access does not make every message free.

Consult [Meta’s platform pricing](https://business.whatsapp.com/products/platform-pricing) when separating transport charges from application and engineering costs.

## Give one uncertain send a recovery owner

Hypothetical example: a custom order update times out after submission, leaving the operator unsure whether it was accepted. Ask the proposed implementation owner how they inspect the request, avoid duplicate customer messages and reconnect the eventual reply to the correct order. Record the supporting logs and access needed before approving the architecture.

Then ask who updates template variables when Shopify product or fulfillment data changes. Compare that maintained process with the supported WhatFlow Business API configuration, including the staff inbox. A custom build can be justified by a real requirement, but the engineering estimate should include these ordinary operating tasks and a handover another developer can use.

Write down who owns retries, duplicate events, template updates, access control and incident response. Ask that person to estimate ongoing maintenance as well as initial development.

Check [supported visual workflow options](https://whatflow.tech/compare/shopify-flow-whatsapp-vs-zapier) before commissioning an additional custom step.

## WhatFlow’s allowance and team costs

For a concrete baseline, consider 5,000 sent messages in a month. Among the listed WhatFlow plans, Plus produces an app-side cost of $9.99 at that volume. This calculation uses its $9.99 base, 5,000 included sends and $0.004 rate above the allowance. It assumes a single monthly allowance and does not include tax or Meta delivery charges. Keep three lines in the budget: the application, applicable WhatsApp delivery fees, and any separate implementation or services.
