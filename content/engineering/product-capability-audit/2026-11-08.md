# WhatFlow product capability audit — November 8, 2026

Scope: checked the public Shopify listings and release notes against the Business API, Team Inbox, and Chat Automation repositories and the previously verified WhatFlow Demo Store screen inventory. Source code helps establish how a capability works; a code path alone does not prove that every merchant, plan, or region has access. No customer messages sent, configurations changed, or site content published for this audit.

## Business API + Team Inbox

| Area | Supported workflows and controls | What to qualify |
| --- | --- | --- |
| Shopify broadcast audience | Start a WhatsApp template broadcast from Shopify Admin using selected customers or the **Use segment** action. View, track, or cancel eligible sends in the broadcast queue. | A merchant launching a campaign from a Shopify segment is different from continuous Shopify segment-to-Inbox audience sync. Do not describe the latter as generally live. |
| Inbox campaign audience | Import CSV or Excel and map columns to template fields; choose all eligible existing conversation contacts on the sending channel or select specific contacts. | “Audience auto-sync” in the conversation picker refers to existing contacts on that channel, not Shopify segment synchronization. Contact availability does not establish consent. |
| Campaign creation and execution | Choose a synced Meta template, personalize variables, preview the message, send to a test number, save a draft, send now or schedule. Campaign queue paces sends; reports show recipient status, failure detail, retry for failed recipients and export. | State approval, eligibility, and Meta charges separately; the app's controls do not guarantee delivery. Avoid claiming built-in campaign A/B experimentation or a full segmentation engine without evidence. |
| Acquisition and sales | Theme storefront button, product-page Order via WhatsApp block, conversation starters and commands, catalog sync and sharing, product and catalog messages, WhatsApp cart follow-up with a Shopify checkout link. | Checkout link points to Shopify. Do not claim built-in WhatsApp payments. Catalog sync and number eligibility can affect setup. |
| Lifecycle | Multi-step abandoned-checkout reminders; unpaid draft-order follow-up; back-in-stock product-page signup, requests queue and messaging; review requests timed to delivery or fulfillment, with a published Judge.me Flow template. | Review workflows request reviews rather than guarantee collection. The Judge.me integration has its own prerequisites. |
| Operations | Order placed/confirmed/paid/cancelled/fulfilled messages, admin notifications, shipment stage and tracking updates, configurable payment-method targeting, COD checkout controls and response-based order tagging. OTP configuration for supported Shopify surfaces. | Separate controlling COD availability at checkout from confirming the order via WhatsApp; make Shopify plan and extension placement dependencies explicit in instructions. |
| Team Inbox | Shared conversations, separate owner/agent accounts, ownership and assignment, internal notes, labels, search, keyboard shortcuts, typing collision warnings, saved drafts, personalized canned responses, media and voice notes, message status/error details. | No inbox seat fees according to the product docs. Live Inbox must be enabled to store new messages and reply through it. |
| Contact and consent tools | Shopify contact import/sync, custom fields for contacts and conversations, shared blocklist, configurable opt-out handling and STOP/START handling. | Contact sync is separate from dynamic campaign audience sync. Test opt-out handling for each workflow and message type; do not imply legal compliance from using the app alone. |
| Automation builder | Shopify Flow actions for approved templates, text, buttons, links and supported media. Triggers for incoming text/media, button/list selection, order reply, opt-out, catalog order and product messages. Separate Inbox workflows support decisions, waits and API invocation. WhatsApp Flows are interactive in-chat forms, a third distinct surface. Webhooks have delivery logs, tests and retry controls. | Which message types can be sent depends on the service window and WhatsApp rules. Clearly label Shopify Flow vs WhatsApp Flows vs Inbox Workflows. |
| Native Shopify Admin | Admin message blocks and one-off/bulk actions on supported order, customer, draft-order and abandoned-checkout surfaces. Template event picker, editable variants and example library. | Document which block/action appears on which surface; a repo extension does not imply availability on every plan or checkout placement. |
| Analytics | Send, delivery, read, failure and reply activity; breakdowns by automation, template, category, country, and costs where supported. Campaign reports provide recipient-level data. Recovery revenue uses Shopify attribution after shoppers click recovery links and complete purchases. Store Report returns a configured Shopify sales summary to an authorized number. | Delivery, reads, replies and purchases are different measures. Demo statistics are not benchmarks. Shopify recovery attribution is not proof of incremental uplift or a blanket report for every campaign. |
| AI and account setup | Shopify Sidekick can assist with workflow/message drafts. External AI clients connect through the WhatFlow MCP connector, with permissions for conversation tools, order lookup and broadcast drafts. Meta Embedded Signup supports eligible existing numbers, and connection health is visible in admin. | External AI integrations are distinct from a built-in autonomous AI chatbot. The MCP broadcast tool creates a draft; it does not send or schedule it. Existing-number eligibility is not universal. |
| Additional capability needing a separate availability check | FlowSense order insights and order-risk workflow use cases are visible in the Business API repository. | Check enrollment, scope and production availability before promoting it in general feature pages or promising specific fraud outcomes. |

## Chat Automation (linked-device)

The separate Shopify app uses an unofficial linked-device connection. Its listing and app source confirm order and fulfillment notifications, cancellation, admin notifications, checkout and draft-order recovery, promotional bulk messages, auto replies, customer/segment broadcast admin actions, order tagging and storefront/direct-order buttons. It also has its own Shopify Flow actions, queue, and usage reporting. The listing advertises back-in-stock alerts. The public recommendation should distinguish the connection model and tested workload; do not transfer official API features, Team Inbox capabilities, consent or pricing assumptions wholesale to Chat Automation.
