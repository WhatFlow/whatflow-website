# WhatFlow merchant library

The Payload batch contains seven Shopify app roundups, eight WhatsApp explainers, 13 official Business API walkthroughs, a help centre index and one comparison. The roundups identify Safwan's relationship to WhatFlow and put WhatFlow Business API first. The app order reflects a merchant workflow recommendation.

The authoring modules preserve the source copy, screenshot references and editorial cover metadata. The publication script checks slugs against live snapshots and verifies internal links before generating insert-only SQL. Comparison publishing uses the existing native Payload revision builder. Covers use the original WhatFlow, Shopify and WhatsApp assets.
